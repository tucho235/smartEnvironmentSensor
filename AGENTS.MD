# BME680 Matter Sensor

This project targets ESP32-C3.

Framework:
- ESP-IDF
- ESP-Matter

Sensor:
- Bosch BME680
- I2C

Matter endpoints:
- Temperature Sensor
- Humidity Sensor
- Pressure Sensor

Telemetry:
- MQTT
- InfluxDB/Grafana

Do not replace ESP-IDF with Arduino.
Do not introduce dependencies without documenting them.
